# User Manual — Administrator

## 1. Role and responsibilities

The Administrator manages system-level setup and user access. Administrator access should be given only to authorized staff.

## 2. Sign in

1. Start the LMS.
2. Enter your administrator username and password.
3. Confirm that the Administrator menu is displayed.

If login fails, check the username/password and contact the designated system administrator if the account needs resetting. Do not share passwords.

## 3. Main tasks

The application’s exact menu labels may differ; use the matching options displayed by the installed version.

### Manage users
1. Open the user-management option.
2. Select the relevant operation (view, add, update, or deactivate, if supported).
3. Enter the requested details.
4. Confirm the operation and verify the result.

Assign the correct role. Do not grant Administrator privileges unless required.

### Manage departments
1. Open department management.
2. Choose the relevant create, view, or update operation supported by the menu.
3. Enter the department details.
4. Save and verify the department appears in the list.

### Manage courses
1. Open course management.
2. Select the relevant course operation.
3. Enter the course information and associate it with the correct department if prompted.
4. Verify the saved course.

### Assign lecturers and enrol students
1. Open the relevant assignment/enrolment menu.
2. Select the course and user.
3. Confirm the association.
4. Check that the lecturer or student can see the appropriate course after signing in.

## 4. Security and good practice

- Use a strong, unique password.
- Never share administrator credentials.
- Assign the least privilege needed.
- Verify user identity before changing account access.
- Keep database backups in an approved secure location.
- Sign out or close the application when finished.

## 5. Troubleshooting

- **A user cannot log in:** verify the account exists, is active, and has the correct role.
- **A user cannot see a course:** check course assignment or enrolment.
- **A change does not appear:** refresh/reopen the relevant menu and check whether the operation was confirmed.
- **Unexpected error:** record the action, error text, and time; report it to the project maintainer.
